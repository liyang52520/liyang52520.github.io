## 一、Java 示例：欧几里得距离

欧几里得距离公式相信大家都不陌生，行内写法：$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$。

推广到 $n$ 维空间，两个向量 $\mathbf{a} = (a_1, a_2, \dots, a_n)$ 和 $\mathbf{b} = (b_1, b_2, \dots, b_n)$ 之间的距离为：

$$
d(\mathbf{a}, \mathbf{b}) = \sqrt{\sum_{i=1}^{n} (a_i - b_i)^2}
$$

下面是 Java 实现：

```java
import java.util.Arrays;

public class EuclideanDistance {

    /**
     * 计算两个向量的欧几里得距离
     * 公式：d = sqrt(Σ(a_i - b_i)²)
     */
    public static double distance(double[] a, double[] b) {
        if (a.length != b.length) {
            throw new IllegalArgumentException("向量维度必须相同");
        }

        double sum = 0.0;
        for (int i = 0; i < a.length; i++) {
            double diff = a[i] - b[i];
            sum += diff * diff;  // 累加平方项: Σ(a_i - b_i)²
        }
        return Math.sqrt(sum);   // 开根号: √(...)
    }

    // 使用 Stream API 的函数式写法
    public static double distanceStream(double[] a, double[] b) {
        return Math.sqrt(
            java.util.stream.IntStream.range(0, a.length)
                .mapToDouble(i -> Math.pow(a[i] - b[i], 2))
                .sum()
        );
    }

    public static void main(String[] args) {
        double[] point1 = {0, 0, 0};
        double[] point2 = {3, 4, 12};

        double d = distance(point1, point2);
        System.out.printf("距离 = %.4f\n", d);
        // 验证: √(3² + 4² + 12²) = √(9+16+144) = √169 = 13
    }
}
```

上面的时间复杂度是 $O(n)$，空间复杂度 $O(1)$，非常高效。

## 二、JSON 配置：梯度下降参数

在机器学习中，梯度下降的参数更新规则为：

$$
\theta_{t+1} = \theta_t - \alpha \cdot \nabla J(\theta_t)
$$

其中 $\alpha$ 是学习率，$\nabla J(\theta)$ 是损失函数 $J(\theta)$ 的梯度。偏导数形式展开：

$$
\frac{\partial J}{\partial \theta_j} = \frac{1}{m} \sum_{i=1}^{m} \left( h_\theta(x^{(i)}) - y^{(i)} \right) \cdot x_j^{(i)}
$$

一份典型的模型参数配置（JSON）如下：

```json
{
  "model": "linear_regression",
  "hyperparameters": {
    "learning_rate": 0.01,
    "epochs": 1000,
    "batch_size": 32,
    "optimizer": "sgd"
  },
  "regularization": {
    "type": "L2",
    "lambda": 0.001
  },
  "features": ["x1", "x2", "x3"],
  "target": "y",
  "train_test_split": 0.8
}
```

L2 正则化的损失函数：

$$
J_{\text{reg}}(\theta) = \frac{1}{2m} \sum_{i=1}^{m} \left( h_\theta(x^{(i)}) - y^{(i)} \right)^2 + \frac{\lambda}{2m} \sum_{j=1}^{n} \theta_j^2
$$

## 三、Python 示例：矩阵运算

矩阵乘法是线性代数的核心。若 $\mathbf{A} \in \mathbb{R}^{m \times n}$，$\mathbf{B} \in \mathbb{R}^{n \times p}$，则：

$$
\mathbf{C} = \mathbf{A} \mathbf{B}, \quad c_{ij} = \sum_{k=1}^{n} a_{ik} \cdot b_{kj}
$$

具体例子：

$$
\begin{bmatrix}
1 & 2 & 3 \\
4 & 5 & 6
\end{bmatrix}
\times
\begin{bmatrix}
7 & 8 \\
9 & 10 \\
11 & 12
\end{bmatrix}
=
\begin{bmatrix}
58 & 64 \\
139 & 154
\end{bmatrix}
$$

Python 实现，包含 NumPy 和纯 Python 两种方式：

```python
import numpy as np
from typing import List


def matrix_multiply(
    A: List[List[float]],
    B: List[List[float]]
) -> List[List[float]]:
    """
    纯 Python 矩阵乘法
    时间复杂度: O(m * n * p)
    """
    m, n = len(A), len(A[0])
    n2, p = len(B), len(B[0])

    if n != n2:
        raise ValueError(f"维度不匹配: ({m}×{n}) × ({n2}×{p})")

    # 初始化结果矩阵 C_{m×p}
    C = [[0.0] * p for _ in range(m)]

    for i in range(m):
        for j in range(p):
            for k in range(n):
                C[i][j] += A[i][k] * B[k][j]

    return C


# ——— NumPy 版本 ———
A = np.array([[1, 2, 3], [4, 5, 6]])
B = np.array([[7, 8], [9, 10], [11, 12]])

# 方式一：dot
C_dot = np.dot(A, B)

# 方式二：@ 运算符 (Python 3.5+)
C_at = A @ B

print("C = \n", C_dot)
# [[ 58  64]
#  [139 154]]
```

## 五、实战：Softmax 函数

Softmax 是分类任务中常用的激活函数，将 logits 转化为概率分布：

$$
\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}
$$

交叉熵损失：

$$
\mathcal{L} = -\sum_{i=1}^{K} y_i \cdot \log(\hat{y}_i)
$$

Python 实现（注意数值稳定性，减去 $\max(z)$）：

```python
import numpy as np


def softmax(z: np.ndarray) -> np.ndarray:
    """
    计算 softmax，数值稳定版本
    softmax(z_i) = exp(z_i - max(z)) / Σ exp(z_j - max(z))
    """
    z_stable = z - np.max(z)  # 防止 exp 溢出
    exp_z = np.exp(z_stable)
    return exp_z / np.sum(exp_z, axis=-1, keepdims=True)


def cross_entropy_loss(y_true: np.ndarray, y_pred: np.ndarray) -> float:
    """
    交叉熵损失: -Σ y_i * log(ŷ_i)
    添加极小值 epsilon 防止 log(0)
    """
    eps = 1e-15
    y_pred = np.clip(y_pred, eps, 1 - eps)
    return -np.sum(y_true * np.log(y_pred))


# 示例
logits = np.array([2.0, 1.0, 0.1])
probs = softmax(logits)
print(f"概率分布: {probs}")
print(f"概率之和: {probs.sum():.6f}")  # 应为 1.0

# 假设计算得到概率，真实标签为 [1, 0, 0]
y_pred = softmax(logits)
y_true = np.array([1.0, 0.0, 0.0])
loss = cross_entropy_loss(y_true, y_pred)
print(f"交叉熵损失: {loss:.6f}")
```
